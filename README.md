# موقع تعريفي بخدمة المينيو الإلكتروني

موقع ثابت (HTML + CSS + JavaScript بس) من صفحتين: الرئيسية (`index.html`) وأعمالنا (`works.html`).
كل النصوص والروابط والأعمال في ملف واحد: `data/content.js`.

## 1. أهم تعديلين قبل ما تبعته لأي عميل

افتح `data/content.js` وغيّر:

```javascript
contact: {
    whatsapp: "201000000000",        // رقمك بصيغة دولية بدون + وبدون صفر في الأول
    displayNumber: "0100 000 0000",  // الرقم اللي بيظهر في الفوتر
    demoUrl: ""                      // رابط مينيو تجريبي شغال (سيبه فاضي لو مفيش)
}
```

رقم الواتساب في المكان ده بس، وكل أزرار الموقع بتاخده منه.

## 2. تغيير اسم الخدمة

`brand.name` في `data/content.js`. الاسم الحالي "مينيو واتساب" اسم مؤقت.
(عنوان الصفحة في تاب المتصفح بيتحدث تلقائي. لو عايز تغيّر كمان `<title>` و`og:title` جوه `index.html` و`works.html` عشان مشاركة الرابط على السوشيال تظهر بالاسم الجديد.)

## 3. إضافة عمل جديد في صفحة "أعمالنا"

في `data/content.js` جوه `works` انسخ عنصر وعدّله:

```javascript
{
    name: "اسم المطعم",
    type: "نوع المطعم أو المنطقة",
    description: "إيه اللي اتعمل للمطعم ده (اكتب حاجات حقيقية بس)",
    tags: ["هوية بصرية مخصصة", "مناطق توصيل"],
    color: "#7A1F2B",                    // لون المطعم (خلفية الكارت)
    logo: "assets/works/اسم-اللوجو.png", // حط الصورة في assets/works
    screenshot: "",                      // اختياري: لقطة شاشة من المينيو
    url: ""                              // رابط المينيو الشغال
}
```

- لو حطيت `screenshot` هتظهر في إطار موبايل بدل اللوجو.
- لو `url` فاضي، بيظهر "رابط المينيو هيتضاف قريب" بدل الزرار.
- لحذف عمل: امسح العنصر بتاعه.

## 4. تعديل النصوص

كل قسم له كتلة واضحة في `data/content.js`: `hero` و`problems` و`features` و`how` و`faq` و`cta`.
عدّل النص جوه علامات التنصيص بس.

## 5. تغيير الألوان والخطوط

أول ملف `css/style.css` داخل `:root`:
`--green` اللون الأساسي، `--saffron` لون الزرار البارز في آخر الصفحة، `--red` لون المشاكل.

## 6. الرفع على GitHub Pages

1. أنشئ مستودع جديد وارفع محتويات المجلد ده (مش المجلد نفسه) في الجذر.
2. `Settings` ثم `Pages` ثم اختار الفرع `main` والمجلد `/ (root)` واحفظ.
3. بعد دقيقة الموقع يظهر على `https://username.github.io/repo-name/`.

بعد كده أي تعديل في `content.js` وارفعه، والموقع يتحدث.

## هيكل الملفات

```text
index.html        الصفحة الرئيسية (هيكل فقط)
works.html        صفحة الأعمال (هيكل فقط)
css/style.css     التصميم
js/site.js        بيبني الصفحات من content.js (مش محتاج تعدّله)
data/content.js   كل المحتوى (عدّل هنا)
assets/works/     لوجوهات ولقطات الأعمال
```
